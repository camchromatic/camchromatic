Tips and tricks

Basics

  • Type code on the left; the preview updates as you go. Your draft is saved in this browser.
  • Add a Citizen ID to see your own avatar and name.
  • Copy code, then paste it into your recolor.me bio (10,000 characters max).
  • Fit check shows only what fits without scrolling (520 × 310px).

Text

  • Use hex colors (like #ad533b). Pick one from your avatar with Pick color from avatar.
  • Set your own text color: Night mode turns plain text light gray.
[center][size=5][b]Your Name[/b][/size] [color=#ad533b]pronouns · a fun fact[/color][/center]
[gradient start=#ff6699 end=#6699ff]Rainbow text[/gradient]

Layout

  • Columns are about 240px each. Put formatting inside each column.
  • Put a [hidden] button at the bottom to tuck away the rest.
  • If Enter doesn't add space, use [br].
[columns][b]Likes[/b] art, tea[nextcol][b]Dislikes[/b] mornings[/columns]
[hidden=Read more]More about me...[/hidden]

Images

  • Usable width is about 500px. Only height resizes: [img height=100].
  • Your avatar fades in over the top-left of the bio (about 200 × 90px).
  • [img right] floats a big picture over the bio; [img align=right] lets text wrap around it.
[img height=100]IMAGE URL[/img]

Box tricks

  • Solid background: wrap your whole bio in a box. It hides the faded avatar and keeps colors the same in Night mode.
  • Border: a box inside a box. Pill label: radius=20 padding=4.
[box bgcolor=ffffff radius=0 padding=10]Your whole bio[/box]
[box bgcolor=999999 padding=3][box bgcolor=ffffff]Framed[/box][/box]
